Track 3
Interventions and Causality
Measuring what changes in LLM behaviour

What is the causal effect of an intervention (a prompt, a tuning step, a model change) on a measurable aspect of a model’s behaviour?

Possible perspectives
  • Prompt level: persona, language, framing, wording, order of examples
  • Training level: base vs instruction-tuned, fine-tuning, model size
  • Inference level: quantisation, decoding, context length
  • Outcomes: sycophancy, accuracy, calibration, refusals, style, bias
  • Heterogeneous effects: where is the effect larger or reversed?
  • Prompt optimisation: does an optimised prompt generalise?
A good project has
  • A formalised design: treatment, control, outcome, unit, quantity to estimate
  • One change at a time: paired prompts, content controlled
  • A validly measured outcome: validated on a hand-annotated sample
  • Quantified uncertainty: intervals, paired tests, effect sizes; threats to validity
Common pitfalls
  • A few prompt variants, “one works better”, with no design or uncertainty
  • Conditions that differ in more than one respect
  • A causal effect on behaviour read as an explanation of the mechanism (Track 6)
