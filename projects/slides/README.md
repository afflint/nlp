# Final projects 2026–27: introductory slides

Slides to introduce the final projects of the Natural Language Processing course (themes and guidelines), built from `../nlp-projects-2026-27.md` with the template and style of the deck "AI, Ethics and Language".

Open `index.html` in a browser (self-contained, works offline). Keys: arrows to move, `t` to switch light/dark theme.

```
python3 serve.py        # http://localhost:8765, rebuilds and reloads on every save
python3 build.py        # rebuild index.html from template.html + slides/*.html + css + js
```

`index.html` is **generated**: edit the files in `slides/`, `css/` and `js/`, never `index.html`.
